# Vehicle Handlers

Vehicle Handlers is a standalone Schedule I mod that adds a hireable Handler/Driver employee for moving the player's existing owned vehicles to property loading bays without duplicating vehicles or bypassing normal delivery reservations.

## Current status

**The Schedule I 0.4.7f12 IL2CPP compatibility layer, shared internal contracts, and distinct Vehicle Handler hiring integration are complete. The fixer gains a separate Vehicle Handler choice while the vanilla Handler/packager remains unchanged; hiring, loaded-save attachment, and the orange appearance cue still require in-game verification before general installation.**

The first release will support one owned vehicle and one destination loading bay per Handler. A Handler uses the normal employee lifecycle for hiring, wages, beds, lockers, saves, firing, and leaving work. Vehicle travel is represented by a short timed trip using the same physical vehicle, followed by reservation-aware placement in the selected loading bay.

## Planned workflow

1. Hire a Handler through the normal employee hiring flow.
2. Use the management clipboard to select one owned vehicle.
3. Select an owned destination property and one of its loading bays.
4. Allow the Handler to reserve the bay, move the same vehicle, and wait when the bay is unavailable.
5. Use **Load into bay** or **Hide/release bay** to make the vehicle available for configuration or clear the bay for a store delivery.

Supported destination properties are Barn, Bungalow, Storage Unit, Dock Warehouse, and Mansion.

## Building

Use references generated by the exact target game version. Do not commit them.

```powershell
.\scripts\verify-game-api.ps1 -MelonLoaderRoot "<path-to-MelonLoader>"
.\scripts\verify-contracts.ps1 -DotNet "<path-to-dotnet>"
.\scripts\build-il2cpp.ps1 -MelonLoaderRoot "<path-to-MelonLoader>"
```

The expected output is `bin/Il2Cpp/VehicleHandlers.dll`.

## Safety boundary

Never commit game assemblies, generated IL2CPP assemblies, MelonLoader binaries, logs, saves, credentials, local toolchains, or personal game data. Release archives contain the mod DLL and installation documentation only.
