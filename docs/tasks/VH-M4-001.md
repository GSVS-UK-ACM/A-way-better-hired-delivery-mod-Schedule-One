## Behaviour

- Reservations use the complete property code, dock GUID, and dock index.
- Ownership uses the complete Handler ID and trip ID, plus an opaque positive lease token.
- Acquisition is atomic and idempotent for the same owner.
- Another owner cannot displace an existing lease.
- Release requires the exact owner and token, so stale cleanup cannot release a newer lease.
- Handler lifecycle cleanup, save loading, and mod shutdown clear process-local leases.
- The exact `DeliveryManager.IsLoadingBayFree(Property, int)` postfix preserves vanilla `false` results and changes a vanilla `true` result to `false` when a Handler lease exists.
